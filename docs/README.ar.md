# تطبيق الملاحظات

مشروع بسيط كامل المكدس يُستخدم كنقطة بداية لتجربة التطوير في هذا المستودع. يتكوّن من مساحتي عمل npm:

- **`client/`** — تطبيق صفحة واحدة باستخدام React + Vite + TypeScript.
- **`server/`** — واجهة REST باستخدام Express + TypeScript مع تخزين الملاحظات في ملف.

في بيئة التطوير، يوجّه Vite طلبات `/api/*` إلى الخادم، لذا يمكنك تشغيل كل شيء معاً والتفاعل عبر عنوان واحد.

## المتطلبات

- Node.js `>= 20` (تم التطوير على Node 22)
- npm `>= 10`

## البدء

```bash
npm install        # تثبيت تبعيات كل مساحة العمل
npm run dev        # تشغيل الواجهة (:5173) والخادم (:3001) معاً
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

للبناء الإنتاجي، يقدّم الخادم أيضاً الواجهة المُجمّعة:

```bash
npm run build
npm start          # http://localhost:3001 (الواجهة + API)
```

## الأوامر الشائعة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل الواجهة والخادم معاً مع إعادة التحميل التلقائي |
| `npm run dev:server` | تشغيل واجهة Express API فقط على المنفذ `3001` |
| `npm run dev:client` | تشغيل خادم Vite للتطوير فقط على المنفذ `5173` |
| `npm test` | تشغيل اختبارات Vitest في كل مساحة عمل |
| `npm run typecheck` | فحص الأنواع في كل مساحة عمل |
| `npm run lint` | فحص ESLint على المستودع |
| `npm run build` | بناء الخادم والواجهة للإنتاج |
| `npm start` | تشغيل API والواجهة المُجمّعة على المنفذ `3001` |

## واجهة API

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الصحة (`persist`: `ok`، `degraded`، أو `unavailable`) |
| `GET` | `/api/notes` | قائمة الملاحظات (الأحدث أولاً) |
| `GET` | `/api/notes/export` | تحميل كل الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | جلب ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء ملاحظة `{ title, body? }` |
| `PUT` | `/api/notes/:id` | تحديث جزئي `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة |

العناوين محدودة بـ 200 حرف والنص بـ 8000. JSON غير صالح أو عنوان مفقود يُرجع `400`. تحديث `PUT` جزئي: الحقول غير المُمرَّرة تُحفظ قيمها. مسارات `/api` غير المعروفة تُرجع JSON `404`. تُحفظ الملاحظات في `server/data/notes.json` (يمكن تغيير المسار عبر `NOTES_DATA_FILE`) لتبقى بعد إعادة تشغيل API. الكتابة ذرية (ملف مؤقت ثم إعادة التسمية). فشل الكتابة على القرص يُرجع `503` ويُرجع الحالة في الذاكرة. مراقب الملفات يتجاهل `server/data` حتى لا يُعاد تشغيل الخادم عند الحفظ. الملف التالف أو غير القابل للقراءة لا يُستبدل أبداً، وعند ذلك تُرجع قائمة الملاحظات `503` بدلاً من قائمة فارغة. الطوابع الزمنية المُحمَّلة تُوحَّد إلى UTC ISO-8601 لضمان الترتيب وعرض «معدّلة» بشكل صحيح. السجلات غير الصالحة (عناوين فارغة، حقول طويلة، تواريخ خاطئة، أو معرّفات مكررة) تُتخطى: الصحة تُبلغ `degraded`، ويمكن عرض الملاحظات الصالحة، والكتابة تُرجع `503` حتى يُصلح الملف.

## الواجهة

- تتبع لغة المتصفح (بما في ذلك العربية واتجاه RTL)
- بحث يدعم متغيرات الألف والتشكيل في العربية، الهمزة على الواو والياء، الياء والكاف الفارسية، الأرقام العربية الشرقية، علامات اللاتين، والمسافات الزائدة
- تأكيد قبل الحذف
- إخراج الملاحظات الظاهرة بصيغة JSON أو Markdown

## متغيرات البيئة

| المتغير | الافتراضي | يُستخدم في | الوصف |
| --- | --- | --- | --- |
| `PORT` | `3001` | الخادم | منفذ HTTP |
| `HOST` | `0.0.0.0` | الخادم | عنوان الاستماع |
| `NOTES_DATA_FILE` | `server/data/notes.json` | الخادم | مسار ملف JSON للملاحظات |
| `VITE_API_TARGET` | `http://127.0.0.1:3001` | الواجهة (تطوير) | وجهة بروكسي Vite لـ `/api` |
