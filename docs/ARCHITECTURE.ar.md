# المعمارية

تطبيق الملاحظات نظام كامل المكدس صغير: واجهة React وواجهة REST عبر Express.
التخزين ملف JSON واحد على القرص، وليس قاعدة بيانات.

## مخطط عالي المستوى

```text
المتصفح (React + Vite)
  │  /api/*  (تطوير: بروكسي Vite → :3001)
  ▼
Express API  (server/src/app.ts)
  │
  ▼
NotesStore   (server/src/notesStore.ts)
  │
  ▼
ملف JSON     (NOTES_DATA_FILE أو server/data/notes.json)
```

في الإنتاج (`npm run build && npm start`) يخدم Express أيضاً `client/dist`
ويرجع إلى `index.html` لمسارات الـ SPA (المسارات بلا امتداد ملف).

## الـ Workspaces

| الحزمة | الدور | نقاط الدخول الرئيسية |
| --- | --- | --- |
| `client` | الواجهة، البحث، تنزيل التصدير | `src/App.tsx`, `src/api.ts`, `src/i18n.ts`, `src/exportNotes.ts` |
| `server` | الـ API، التخزين، تصدير الخادم | `src/index.ts`, `src/app.ts`, `src/notesStore.ts`, `src/exportNotes.ts` |
| الجذر | npm workspaces و ESLint والأوامر المشتركة | `package.json`, `eslint.config.js` |

## تدفق الطلب

1. الواجهة تستدعي `/api/notes` (والمسارات ذات الصلة) عبر `client/src/api.ts`.
2. في التطوير يوجّه Vite مسار `/api` إلى `VITE_API_TARGET` (الافتراضي `http://127.0.0.1:3001`). إن كان الـ API متوقفاً يرجع البروكسي JSON بحالة `502` مع `{ "error": "api unreachable" }`.
3. `createApp()` يربط المسارات، تحويل أخطاء التحقق/التخزين، والاستضافة الثابتة الاختيارية مع مسار الـ SPA.
4. `NotesStore` يحتفظ بـ `Map` في الذاكرة، يحمّل من القرص عند الإقلاع، ويكتب ذرّياً (`*.tmp` ثم `rename`).

## نموذج التخزين

كل ملاحظة:

```ts
{
  id: string;        // UUID
  title: string;     // مطلوب، بعد القصّ، ≤ 200 حرف
  body: string;      // بعد القصّ، ≤ 8000 حرف (يُسمح بالفراغ)
  createdAt: string; // UTC ISO-8601
  updatedAt: string; // UTC ISO-8601
}
```

تُرتَّب القائمة حسب أحدث `updatedAt`. تُطبَّع الطوابع الزمنية من القرص إلى
UTC ISO-8601 حتى تبقى الفرز ووسم «معدّلة» صحيحة رغم اختلاف الصيغ.

### صحة التخزين (`persistStatus`)

| الحالة | المعنى |
| --- | --- |
| `ok` | تحميل نظيف (أو لا ملف بعد / ذاكرة فقط) |
| `degraded` | تُجاهلت سجلات غير صالحة؛ الملاحظات الصالحة قابلة للقراءة؛ الكتابة مرفوضة |
| `unavailable` | الملف غير مقروء/تالف ولا ملاحظات صالحة؛ القائمة/الجلب ترمي خطأ؛ الكتابة مرفوضة |

الملفات التالفة أو الجزئية **لا تُستبدل أبداً**. فشل الكتابة يعيد الحالة في
الذاكرة ويرجع `503`.

مستثنى مجلد `server/data` من مراقب الملفات حتى لا يعيد حفظ ملاحظة تشغيل
`tsx watch`.

## سلوك العميل

- اللغة: `detectLocale()` من لغة المتصفح؛ العربية (`ar` / `ar-*`) تفعّل RTL والنصوص العربية.
- البحث: `normalizeForSearch()` يوحّد الألف/التشكيل/الهمزة، الياء/الكاف الفارسي، الأرقام الشرقية، اللاتينية المنبّرة، والمسافات الزائدة.
- التصدير: الواجهة تصدّر الملاحظات **المطابقة للبحث حالياً** كـ JSON أو Markdown عبر تنزيل Blob.
- حماية التعديل: تأكيد عند الإلغاء؛ `beforeunload` عند وجود تغييرات؛ Escape يلغي مع تأكيد عند الحاجة.
- إعادة محاولة التحميل الأولي عند أخطاء الشبكة أو `502`/`504` من البروكسي.

## صيغ التصدير

شكل مشترك بين العميل والخادم:

- **JSON**: `{ exportedAt, count, notes }` بتنسيق جميل، اسم الملف `notes-YYYY-MM-DD.json`
- **Markdown**: عنوان `# Notes` ثم أقسام `## العنوان` مع النص ومعرّفات الوقت، اسم الملف `notes-YYYY-MM-DD.md`

تصدير الخادم (`GET /api/notes/export`) يصدّر **كل** الملاحظات المخزّنة.
أزرار الواجهة تصدّر القائمة **المُصفّاة**.

## ملاحظات أمان/تقوية

- تعطيل `X-Powered-By`
- استجابات الـ API: `Cache-Control: no-store` و `X-Content-Type-Options: nosniff`
- حد جسم JSON الافتراضي `256kb`
- أصول `/assets/*` المُجزّأة تحصل على كاش طويل؛ `index.html` بلا تخزين
- الملفات الثابتة الناقصة ذات الامتداد ترجع `404` (بلا رجوع SPA لمسارات مثل `/favicon.ico`)
