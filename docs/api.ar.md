# مرجع واجهة برمجة التطبيقات (API)

[العودة إلى README العربية](../README.ar.md)

واجهة REST تُرجع JSON دائماً. المسار الأساسي هو `/api` وجميع الاستجابات
تحمل الترويسات `Cache-Control: no-store` و `X-Content-Type-Options: nosniff`.
الحد الأقصى لحجم جسم الطلب هو `256kb`؛ تجاوزه يعيد `413`.

أثناء التطوير تصل إلى الواجهة عبر خادم Vite على
`http://localhost:5173/api/...` (وكيل إلى الخادم)، أو مباشرة على
`http://localhost:3001/api/...`.

## نموذج البيانات

الملاحظة (Note):

| الحقل | النوع | الوصف |
| --- | --- | --- |
| `id` | string | معرّف UUID يولّده الخادم |
| `title` | string | العنوان، إلزامي، بحد أقصى 200 حرف بعد إزالة المسافات الطرفية |
| `body` | string | النص، اختياري، بحد أقصى 8000 حرف (سلسلة فارغة إن لم يُرسل) |
| `createdAt` | string | وقت الإنشاء بصيغة ISO-8601 بتوقيت UTC |
| `updatedAt` | string | وقت آخر تعديل بصيغة ISO-8601 بتوقيت UTC |

يزيل الخادم المسافات الطرفية من `title` و `body` قبل التحقق والحفظ.

## نقاط النهاية

### `GET /api/health` — فحص الصحة

```bash
curl http://localhost:3001/api/health
```

```json
{
  "status": "ok",
  "persist": "ok",
  "uptime": 12.34
}
```

قيم `persist`:

| القيمة | المعنى |
| --- | --- |
| `ok` | ملف البيانات سليم؛ القراءة والكتابة تعملان |
| `degraded` | تخطّى الخادم سجلات غير صالحة عند التحميل؛ القراءة ممكنة، الكتابة تعيد `503` |
| `unavailable` | تعذّر تحميل ملف البيانات كلياً؛ القراءة والكتابة تعيدان `503` |

عندما لا تكون الحالة `ok` تأخذ `status` القيمة نفسها التي في `persist`.

### `GET /api/notes` — قائمة الملاحظات

تعيد مصفوفة ملاحظات مرتبة تنازلياً حسب `updatedAt` (الأحدث أولاً).

```bash
curl http://localhost:3001/api/notes
```

```json
[
  {
    "id": "0b6f7f2e-...",
    "title": "ملاحظة تجريبية",
    "body": "النص هنا",
    "createdAt": "2026-08-20T06:00:00.000Z",
    "updatedAt": "2026-08-20T06:05:00.000Z"
  }
]
```

### `GET /api/notes/export` — تصدير الملاحظات

تنزّل جميع الملاحظات ملفاً واحداً. معامل `format` اختياري:

| القيمة | النتيجة |
| --- | --- |
| بدون معامل أو `json` | ملف `notes-YYYY-MM-DD.json` بنوع `application/json` |
| `md` أو `markdown` | ملف `notes-YYYY-MM-DD.md` بنوع `text/markdown` |
| أي قيمة أخرى | `400` مع `{ "error": "format must be json or md" }` |

```bash
curl -OJ "http://localhost:3001/api/notes/export?format=md"
```

صيغة JSON تعيد كائناً يضم `exportedAt` و `count` و `notes`. صيغة Markdown
تعيد مستنداً بعنوان لكل ملاحظة مع نصّها وبياناتها الوصفية (المعرّف
ووقتَي الإنشاء والتعديل).

### `GET /api/notes/:id` — جلب ملاحظة واحدة

```bash
curl http://localhost:3001/api/notes/0b6f7f2e-...
```

تعيد الملاحظة، أو `404` مع `{ "error": "note not found" }` إن لم توجد.

### `POST /api/notes` — إنشاء ملاحظة

الجسم: `{ "title": string, "body"?: string }`. الحقل `body` اختياري؛
إن أُرسل بنوع غير نصّي يُتجاهل ويُحفظ نصاً فارغاً.

```bash
curl -X POST http://localhost:3001/api/notes \
  -H "Content-Type: application/json" \
  -d '{ "title": "ملاحظة جديدة", "body": "النص" }'
```

تعيد `201` مع الملاحظة المنشأة كاملة.

### `PUT /api/notes/:id` — تحديث جزئي

الجسم: `{ "title"?: string, "body"?: string }`. تحديث جزئي فعلاً:
الحقول غير المرسلة (أو المرسلة بقيمة `undefined`) تحتفظ بقيمها الحالية.
إرسال جسم بلا أي من الحقلين يعيد `400` مع
`{ "error": "title or body is required" }`.

```bash
curl -X PUT http://localhost:3001/api/notes/0b6f7f2e-... \
  -H "Content-Type: application/json" \
  -d '{ "body": "نص محدّث فقط" }'
```

تعيد `200` مع الملاحظة بعد التحديث (وتحدّث `updatedAt` فقط إذا تغيّر
محتوى فعلي). ملاحظة غير موجودة تعيد `404`.

### `DELETE /api/notes/:id` — حذف ملاحظة

```bash
curl -X DELETE http://localhost:3001/api/notes/0b6f7f2e-...
```

تعيد `204` بلا جسم عند النجاح، أو `404` إن لم توجد الملاحظة.

## الأخطاء

جميع الأخطاء بصيغة `{ "error": "..." }`:

| الرمز | الحالة |
| --- | --- |
| `400` | عنوان مفقود، عنوان أطول من 200 حرف، نص أطول من 8000 حرف، JSON غير صالح، أو `PUT` بلا حقول |
| `404` | ملاحظة غير موجودة، أو مسار مجهول تحت `/api` |
| `413` | جسم الطلب أكبر من `256kb` |
| `503` | فشل الكتابة على القرص (مع تراجع عن التغيير في الذاكرة)، أو ملف بيانات تالف يمنع القراءة/الكتابة |
| `500` | خطأ داخلي غير متوقع |

رسائل التحقق الحرفية:

- `title is required`
- `title must be at most 200 characters`
- `body must be at most 8000 characters`
- `title or body is required` (خاصة بـ `PUT`)

## التخزين والمتانة

- تُحفظ الملاحظات في `server/data/notes.json`، ويمكن تغيير المسار عبر
  متغيّر البيئة `NOTES_DATA_FILE`.
- الكتابة ذرّية: يُكتب ملف مؤقت (`*.tmp`) ثم يُعاد تسميته فوق الملف
  الأصلي، فلا يُترك الملف في حالة وسطى أبداً.
- كل عملية كتابة (إنشاء/تحديث/حذف) تُثبَّت على القرص فوراً؛ إن فشلت
  الكتابة يتراجع الخادم عن التغيير في الذاكرة ويعيد `503`.
- عند الإقلاع يحمّل الخادم الملف ويتحقق من كل سجل. السجلات غير الصالحة
  (عناوين فارغة، حقول أطول من الحد، تواريخ غير صالحة، معرّفات مكررة)
  تُتخطى، ويتحوّل فحص الصحة إلى `degraded`، وتُرفض الكتابة كي لا
  يُستبدل الملف الأصلي — أصلح الملف يدوياً ثم أعد تشغيل الخادم.
- إذا تعذّر تحليل الملف كلياً (JSON تالف أو ليس مصفوفة) تصبح الحالة
  `unavailable` وتعيد جميع عمليات القراءة والكتابة `503`.
- الطوابع الزمنية المحمّلة تُوحَّد إلى ISO-8601 بتوقيت UTC حتى لو كانت
  مخزّنة بصيغ مختلطة.

## متغيّرات البيئة

| المتغيّر | الافتراضي | الوصف |
| --- | --- | --- |
| `PORT` | `3001` | منفذ الخادم (يجب أن يكون عدداً صحيحاً بين 1 و 65535) |
| `HOST` | `0.0.0.0` | العنوان الذي يستمع عليه الخادم |
| `NOTES_DATA_FILE` | `server/data/notes.json` | مسار ملف البيانات |
| `VITE_API_TARGET` | `http://127.0.0.1:3001` | وجهة وكيل `/api` في خادم تطوير Vite |
