# تطبيق الملاحظات

[English](README.md) | [العربية](README.ar.md)

تطبيق صغير كامل المكدس يُستخدم لتشغيل تجربة التطوير في هذا المستودع. فيه مساحتا عمل:

- **`client/`** — تطبيق صفحة واحدة بـ React وVite وTypeScript.
- **`server/`** — واجهة REST بـ Express وTypeScript مع تخزين الملاحظات في ملف.

الواجهة تحوّل طلبات `/api/*` إلى الخادم أثناء التطوير، لذلك تشغّل الاثنين معاً وتتفاعل من عنوان واحد.

المزيد: [التوثيق](docs/README.md) · [الواجهة البرمجية](docs/api.ar.md) · [البنية](docs/architecture.ar.md)

## المتطلبات

- Node.js `>= 20` (طُوّر على Node 22)
- npm `>= 10`

## البدء

```bash
npm install        # تثبيت اعتماديات كل مساحات العمل
npm run dev        # تشغيل الواجهة البرمجية (:3001) والعميل (:5173) معاً
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

للبناء الإنتاجي تقدّم الواجهة البرمجية أيضاً العميل المُجمَّع:

```bash
npm run build
npm start          # http://localhost:3001 (الواجهة البرمجية + الواجهة)
```

انسخ [`.env.example`](.env.example) إلى `.env` إذا احتجت تغيير المنافذ أو مسار ملف البيانات. متغيرات البيئة:

| المتغير | الافتراضي | الاستخدام |
| --- | --- | --- |
| `PORT` | `3001` | منفذ استماع Express |
| `HOST` | `0.0.0.0` | عنوان الربط |
| `NOTES_DATA_FILE` | `server/data/notes.json` | مسار ملف JSON |
| `VITE_API_TARGET` | `http://127.0.0.1:3001` | هدف وكيل Vite لمسار `/api` |

## الأوامر الشائعة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل العميل والخادم معاً مع إعادة التحميل |
| `npm run dev:server` | تشغيل واجهة Express فقط على المنفذ `3001` |
| `npm run dev:client` | تشغيل خادم Vite فقط على المنفذ `5173` |
| `npm test` | تشغيل اختبارات كل مساحات العمل (Vitest) |
| `npm run typecheck` | فحص الأنواع في كل مساحات العمل |
| `npm run lint` | فحص المستودع بـ ESLint |
| `npm run build` | بناء الخادم والعميل للإنتاج |
| `npm start` | تقديم الواجهة البرمجية والواجهة المبنية على المنفذ `3001` |

## الواجهة البرمجية

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الصحة (`persist`: `ok` أو `degraded` أو `unavailable`) |
| `GET` | `/api/notes` | قائمة الملاحظات (الأحدث أولاً) |
| `GET` | `/api/notes/export` | تنزيل كل الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | جلب ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء ملاحظة `{ title, body? }` |
| `PUT` | `/api/notes/:id` | تحديث جزئي `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة |

العنوان محدود بـ 200 حرف والنص بـ 8000. JSON التالف والعناوين الناقصة تعيد `400`. `PUT` تحديث جزئي: الحقول المحذوفة تبقي قيمها. مسارات `/api` غير المعروفة تعيد JSON `404`. تُحفظ الملاحظات في `server/data/notes.json` (يمكن تجاوزه بـ `NOTES_DATA_FILE`) فتعود بعد إعادة تشغيل الخادم. الكتابة ذرية (`tmp` ثم rename). فشل الكتابة على القرص يعيد `503` ويتراجع عن حالة الذاكرة. مراقب ملفات الواجهة يتجاهل `server/data` حتى لا تعيد عملية الحفظ تشغيل الخادم. الملف التالف أو غير القابل للقراءة لا يُكتب فوقه، وقائمة الملاحظات حينها تعيد `503` بدل قائمة فارغة. تُطبَّع التواريخ المحمّلة إلى UTC ISO-8601 حتى تُرتَّب الصيغ المختلطة ويظهر «معدّلة» بشكل صحيح. السجلات الباطلة (عناوين فارغة، حقول أطول من الحد، تواريخ سيئة، أو معرّفات مكررة) تُتخطى: الصحة تصبح `degraded`، والملاحظات الصالحة تُعرض، والحفظ يعيد `503` حتى إصلاح الملف.
الواجهة تتبع لغة المتصفح (بما فيها العربية واتجاه RTL)، وتدعم البحث
(بما في ذلك تنويعات الألف والتشكيل، الهمزة على الواو والياء، الياء/الكاف الفارسية،
الأرقام العربية الشرقية، الحركات اللاتينية، والمسافات الزائدة)،
وتطلب تأكيداً قبل الحذف، ويمكنها تصدير الملاحظات الظاهرة كـ JSON أو Markdown.

أمثلة الطلبات والاستجابة ورموز الخطأ: [مرجع الواجهة البرمجية](docs/api.ar.md).

```
└── package.json            # مساحات عمل npm والسكربتات
```
