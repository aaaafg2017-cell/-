# تطبيق الملاحظات

تطبيق كامل المكدس بسيط يُستخدم كأساس لتطوير هذا المستودع. يتكون من مساحتي عمل:

- **`client/`** — واجهة React + Vite + TypeScript (صفحة واحدة).
- **`server/`** — واجهة REST عبر Express + TypeScript مع حفظ الملاحظات في ملف.

في وضع التطوير يوجّه العميل طلبات `/api/*` إلى الخادم، فتعمل الواجهة والـ API من عنوان واحد من وجهة نظر المتصفح.

## المتطلبات

- Node.js `>= 20` (طُوّر على Node 22)
- npm `>= 10`

## البدء السريع

```bash
npm install        # تثبيت اعتماديات كل مساحات العمل
npm run dev        # تشغيل الـ API (:3001) والعميل (:5173) معاً
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

لبناء الإنتاج، يخدم الـ API أيضاً الواجهة المُجمَّعة:

```bash
npm run build
npm start          # http://localhost:3001 (API + الواجهة)
```

النسخة الإنجليزية من هذا الملف: [`README.md`](./README.md).
ملاحظات للمساهمين والوكلاء: [`docs/CONTRIBUTING.ar.md`](./docs/CONTRIBUTING.ar.md).

## واجهة برمجة التطبيقات (API)

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الصحة (`persist`: `ok` أو `degraded` أو `unavailable`) |
| `GET` | `/api/notes` | قائمة الملاحظات (الأحدث أولاً حسب `updatedAt`) |
| `GET` | `/api/notes/export` | تنزيل كل الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | جلب ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء ملاحظة `{ title, body? }` → `201` |
| `PUT` | `/api/notes/:id` | تحديث جزئي `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة → `204` |

### قواعد التحقق والأخطاء

- العنوان إلزامي بعد القصّ، بحد أقصى **200** حرف؛ النص بحد أقصى **8000**.
- JSON غير الصالح أو العنوان الناقص → `400`.
- `PUT` جزئي: الحقول المحذوفة تبقى كما هي؛ جسم فارغ تماماً → `400`.
- حجم جسم الطلب الافتراضي `256kb`؛ الأكبر → `413`.
- مسارات `/api` غير المعروفة → JSON `404`.
- فشل الكتابة على القرص → `503` مع التراجع عن التغيير في الذاكرة.

### نموذج الملاحظة

```json
{
  "id": "uuid",
  "title": "string",
  "body": "string",
  "createdAt": "UTC ISO-8601",
  "updatedAt": "UTC ISO-8601"
}
```

## التخزين والصحة

- الملف الافتراضي: `server/data/notes.json` (يمكن تجاوزه بـ `NOTES_DATA_FILE`).
- الكتابة ذرّية (`*.tmp` ثم `rename`) حتى لا يُفسد الملف عند الانقطاع.
- مجلد `server/data` مستثنى من مراقب الملفات في التطوير حتى لا يعيد تشغيل الخادم عند كل حفظ.
- الملف التالف أو غير القابل للقراءة **لا يُستبدل** تلقائياً.

| حالة `persist` | المعنى | القراءة | الكتابة |
| --- | --- | --- | --- |
| `ok` | تحميل سليم | مسموحة | مسموحة |
| `degraded` | سُجّلت سجلات غير صالحة وتُركت ملاحظات صالحة | مسموحة | مرفوضة (`503`) |
| `unavailable` | الملف تالف / غير مقروء / كل السجلات باطلة | `503` | مرفوضة |

## الواجهة والمستخدم

- اللغة واتجاه الصفحة يتبعان لغة المتصفح (**عربي RTL** أو إنجليزي LTR). لا يوجد مبدّل لغة داخل التطبيق.
- بحث محلي على العنوان والنص مع تطبيع عربي: أشكال الألف، التشكيل، الهمزة على واو/ياء، الياء/الكاف الفارسية، التاء المربوطة، الأرقام الشرقية، والتشكيل اللاتيني، والمسافات الزائدة.
- تأكيد قبل الحذف؛ تحذير عند تجاهل مسودة غير محفوظة؛ `Escape` يلغي التعديل.
- تصدير الملاحظات **الظاهرة في البحث** كـ JSON أو Markdown من المتصفح (لا يستدعي مسار التصدير في الـ API).

## التصدير: مساران

| المصدر | ماذا يُصدَّر | الاستخدام |
| --- | --- | --- |
| أزرار الواجهة | الملاحظات المطابقة لفلتر البحث الحالي | تنزيل من المتصفح |
| `GET /api/notes/export` | **كل** الملاحظات في المخزن | مرفقات HTTP (`notes-YYYY-MM-DD.json\|md`) |

صيغة JSON المشتركة تقريباً: `{ exportedAt, count, notes }`.

## متغيرات البيئة

| المتغير | المكان | الافتراضي | الغرض |
| --- | --- | --- | --- |
| `PORT` | الخادم | `3001` | منفذ الاستماع (1–65535) |
| `HOST` | الخادم | `0.0.0.0` | عنوان الربط |
| `NOTES_DATA_FILE` | الخادم | `server/data/notes.json` | مسار ملف التخزين |
| `VITE_API_TARGET` | Vite (تطوير) | `http://127.0.0.1:3001` | هدف وكيل `/api` |

## ملاحظات وحدود

- لا مصادقة ولا مستخدمون متعددون؛ ملف JSON مشترك — آخر كاتب يفوز عبر العمليات.
- الواجهة لا تستدعي `/api/health` ولا `/api/notes/export` مباشرة.
- بدون بناء العميل، `npm start` يخدم الـ API فقط.
- هذا تطبيق تمهيدي للتطوير، وليس منتج ملاحظات إنتاجي كامل.
