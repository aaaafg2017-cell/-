# تطبيق الملاحظات

*[English](README.md)*

تطبيق بسيط كامل المكدس (full-stack) يُستخدم لتجربة التطوير في هذا المستودع.
يتكوّن من مساحتي عمل (workspaces):

- **`client/`** — تطبيق صفحة واحدة (SPA) مبني بـ React و Vite و TypeScript.
- **`server/`** — واجهة برمجية (REST API) مبنية بـ Express و TypeScript، مع تخزين الملاحظات في ملف.

يقوم العميل (client) بتمرير طلبات `/api/*` إلى الخادم أثناء التطوير، لذا يمكنك
تشغيل الاثنين معًا والتعامل مع رابط واحد فقط.

## المتطلبات

- Node.js الإصدار `20` أو أحدث (تم التطوير على Node 22)
- npm الإصدار `10` أو أحدث

## البدء

```bash
npm install        # تثبيت تبعيات جميع مساحات العمل
npm run dev        # تشغيل الواجهة البرمجية (:3001) والعميل (:5173) معًا
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

للحصول على نسخة إنتاجية (production build)، تقوم الواجهة البرمجية أيضًا بتقديم
العميل المُجمَّع (compiled client):

```bash
npm run build
npm start          # http://localhost:3001 (الواجهة البرمجية + الواجهة الأمامية)
```

## الأوامر الشائعة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل العميل والخادم معًا مع إعادة التحميل التلقائي |
| `npm run dev:server` | تشغيل واجهة Express البرمجية فقط على المنفذ `3001` |
| `npm run dev:client` | تشغيل خادم Vite للتطوير فقط على المنفذ `5173` |
| `npm test` | تشغيل جميع حزم الاختبارات (Vitest) في كل مساحات العمل |
| `npm run typecheck` | فحص الأنواع (types) في كل مساحات العمل |
| `npm run lint` | فحص المستودع بالكامل باستخدام ESLint |
| `npm run build` | بناء الخادم والعميل لبيئة الإنتاج |
| `npm start` | تشغيل الواجهة البرمجية والواجهة الأمامية المبنيتين لبيئة الإنتاج على المنفذ `3001` |

## الواجهة البرمجية (API)

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الحالة الصحية (`persist`: القيم `ok` أو `degraded` أو `unavailable`) |
| `GET` | `/api/notes` | عرض الملاحظات (الأحدث أولاً) |
| `GET` | `/api/notes/export` | تنزيل جميع الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | جلب ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء ملاحظة `{ title, body? }` |
| `PUT` | `/api/notes/:id` | تحديث جزئي لملاحظة `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة |

يقتصر عنوان الملاحظة على 200 حرف والنص على 8000 حرف. البيانات غير الصالحة
(JSON) والعناوين المفقودة تُعيد رمز الحالة `400`. طلب `PUT` هو تحديث جزئي: الحقول
المحذوفة من الطلب تحتفظ بقيمها الحالية. مسارات `/api` غير المعروفة تُعيد `404`
بصيغة JSON. تُحفظ الملاحظات في `server/data/notes.json` (يمكن تجاوز هذا المسار
عبر `NOTES_DATA_FILE`) لتبقى محفوظة بعد إعادة تشغيل الواجهة البرمجية. عمليات
الكتابة ذرّية (atomic) باستخدام ملف مؤقت (`tmp`) وإعادة تسمية (rename). فشل
الكتابة على القرص يُعيد رمز الحالة `503` ويتراجع عن الحالة في الذاكرة. كما أن
مراقب الملفات (file watcher) في الواجهة البرمجية يتجاهل مجلد `server/data` حتى
لا تتسبب عملية حفظ ملاحظة في إعادة تشغيل الخادم. لا يتم استبدال أي ملف تالف أو
غير قابل للقراءة، وفي هذه الحالة يُعيد عرض الملاحظات رمز الحالة `503` بدلًا من
قائمة فارغة. يتم تطبيع (normalize) الطوابع الزمنية المحمَّلة إلى صيغة UTC
ISO-8601 لضمان الترتيب الصحيح وعرض عبارة "معدّلة" حتى مع اختلاف الصيغ. السجلات
غير الصالحة (عناوين فارغة، حقول تجاوزت الحد الأقصى للطول، تواريخ غير صحيحة، أو
معرّفات مكرّرة) يتم تجاهلها: تُصبح حالة الفحص الصحي `degraded`، ويظل عرض
الملاحظات الصالحة ممكنًا، بينما تُعيد عمليات الكتابة رمز الحالة `503` حتى يتم
إصلاح الملف. تتبع الواجهة الأمامية لغة المتصفح (بما فيها العربية واتجاه الكتابة
من اليمين لليسار RTL)، وتدعم البحث (بما في ذلك اختلافات الألف والتشكيل، الهمزة
على الواو والياء، الياء والكاف الفارسية، الأرقام الهندية الشرقية، الحروف
اللاتينية المُشكَّلة، والمسافات الزائدة)، وتطلب التأكيد قبل الحذف، ويمكنها
تصدير الملاحظات المعروضة بصيغة JSON أو Markdown.

## متغيرات البيئة

| المتغيّر | القيمة الافتراضية | الوصف |
| --- | --- | --- |
| `PORT` | `3001` | المنفذ الذي تستمع عليه الواجهة البرمجية (والواجهة الأمامية أيضًا في بيئة الإنتاج). |
| `HOST` | `0.0.0.0` | العنوان/الواجهة التي ترتبط بها الواجهة البرمجية. |
| `NOTES_DATA_FILE` | `server/data/notes.json` | مسار ملف JSON الذي تُحفظ فيه الملاحظات. |
| `VITE_API_TARGET` | `http://127.0.0.1:3001` | عنوان الواجهة البرمجية الذي يمرر إليه خادم Vite طلبات `/api/*`. |
