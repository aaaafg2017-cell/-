# تطبيق الملاحظات

[English](README.md)

تطبيق ملاحظات صغير كامل المكدّس: أنشئ الملاحظات وعدّلها وابحث فيها وصدّرها، مع
بقائها محفوظة بعد إعادة تشغيل الخادم. يتكوّن المستودع من مساحتَي عمل:

- **‏`client/`** — تطبيق صفحة واحدة بـ React و Vite و TypeScript.
- **‏`server/`** — واجهة REST بـ Express و TypeScript تحفظ الملاحظات في ملف.

أثناء التطوير يمرّر العميل كل طلبات `‎/api/*` إلى الخادم، لذا تشغّل الاثنين معاً
وتتعامل مع عنوان واحد فقط.

## المتطلبات

- Node.js إصدار `20` أو أحدث (طُوِّر على Node 22)
- npm إصدار `10` أو أحدث

## البدء السريع

```bash
npm install        # تثبيت اعتماديات مساحات العمل كلها
npm run dev        # تشغيل الواجهة البرمجية (‎:3001) والعميل (‎:5173) معاً
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

في بناء الإنتاج يقدّم الخادم العميل المبني أيضاً:

```bash
npm run build
npm start          # http://localhost:3001 (الواجهة البرمجية + الواجهة الرسومية)
```

## الأوامر الشائعة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل العميل والخادم معاً مع إعادة التحميل الحيّ |
| `npm run dev:server` | تشغيل واجهة Express وحدها على المنفذ `3001` |
| `npm run dev:client` | تشغيل خادم Vite للتطوير وحده على المنفذ `5173` |
| `npm test` | تشغيل كل مجموعات الاختبارات (Vitest) |
| `npm run typecheck` | فحص الأنواع في كل مساحات العمل |
| `npm run lint` | فحص المستودع كاملاً بـ ESLint |
| `npm run build` | بناء الخادم والعميل للإنتاج |
| `npm start` | تقديم الواجهة البرمجية والواجهة المبنية على المنفذ `3001` |

## الواجهة البرمجية

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الصحة (‏`persist`: ‏`ok` أو `degraded` أو `unavailable`) |
| `GET` | `/api/notes` | سرد الملاحظات (الأحدث أولاً) |
| `GET` | `/api/notes/export` | تنزيل كل الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | جلب ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء ملاحظة `{ title, body? }` |
| `PUT` | `/api/notes/:id` | تحديث جزئي لملاحظة `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة |

يجب ألا يتجاوز العنوان 200 حرف ولا نص الملاحظة 8000 حرف. طلبات JSON غير الصالحة
والعناوين الناقصة تُعيد `400`، والمسارات غير المعروفة تحت `‎/api` تُعيد `404`
بصيغة JSON، و`PUT` تحديث جزئي: الحقول غير المرسلة تبقى كما هي. القواعد الكاملة،
بما فيها رسائل الأخطاء وصيغ التصدير، في
[مرجع الواجهة البرمجية](docs/api.md).

تُحفظ الملاحظات في `server/data/notes.json` (يمكن تغيير المسار عبر
`NOTES_DATA_FILE`) بكتابة ذرّية، فتبقى بعد إعادة تشغيل الخادم. لا يُعاد أبداً
كتابة ملف تالف أو يحتوي سجلات غير صالحة: تُبلِّغ الواجهة عن حالة `degraded` أو
`unavailable` وتُعيد `503` للعمليات المتأثرة حتى يُصلَح الملف. التفاصيل في
[صفحة التخزين](docs/persistence.md).

تتبع الواجهة الرسومية لغة المتصفح (بما فيها العربية واتجاه RTL)، وتدعم بحثاً
يتسامح مع صور الألف والتشكيل والهمزة على الواو والياء، والياء والكاف الفارسيتين،
والأرقام العربية الشرقية، والحركات اللاتينية، والمسافات الزائدة. كما تسأل قبل
الحذف وقبل تجاهل تعديلات غير محفوظة، وتستطيع تصدير الملاحظات الظاهرة بصيغة JSON
أو Markdown. التفاصيل في [دليل الواجهة الأمامية](docs/frontend.md).
