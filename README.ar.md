# تطبيق الملاحظات

تطبيق كامل المكدس صغير لتدوين الملاحظات. يتكون من مساحتي عمل:

- **`client/`** — واجهة React + Vite + TypeScript.
- **`server/`** — واجهة REST بـ Express و TypeScript، مع حفظ الملاحظات في ملف JSON.

في وضع التطوير يوجّه العميل طلبات `/api/*` إلى الخادم، لذلك تشغّل الاثنين معاً وتتعامل مع عنوان واحد.

[English README](README.md) · [التوثيق التفصيلي](docs/README.md)

## المتطلبات

- Node.js `>= 20` (طُوّر على Node 22)
- npm `>= 10`

## البدء السريع

```bash
npm install        # تثبيت اعتماديات كل مساحات العمل
npm run dev        # تشغيل الواجهة (:5173) والـ API (:3001) معاً
```

ثم افتح http://localhost:5173 وأنشئ ملاحظة.

للبناء الإنتاجي يقدّم الـ API الواجهة المجمّعة أيضاً:

```bash
npm run build
npm start          # http://localhost:3001 (API + الواجهة)
```

## الأوامر الشائعة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل العميل والخادم معاً مع إعادة التحميل الحي |
| `npm run dev:server` | تشغيل واجهة Express فقط على المنفذ `3001` |
| `npm run dev:client` | تشغيل خادم Vite فقط على المنفذ `5173` |
| `npm test` | تشغيل كل اختبارات Vitest |
| `npm run typecheck` | فحص الأنواع في كل مساحات العمل |
| `npm run lint` | فحص المستودع بـ ESLint |
| `npm run build` | بناء الخادم والعميل للإنتاج |
| `npm start` | تقديم الـ API والواجهة المبنية على المنفذ `3001` |

## ماذا يفعل التطبيق؟

- إنشاء ملاحظة بعنوان ونص اختياري، وتعديلها وحذفها (مع تأكيد قبل الحذف).
- البحث في العنوان والنص مع تطبيع عربي (همزات، تشكيل، ألف، ياء/كاف فارسية، أرقام هندية/عربية مشرقية، مسافات زائدة).
- إخراج الملاحظات الظاهرة كـ JSON أو Markdown.
- لغة الواجهة واتجاهها يتبعان لغة المتصفح (`ar` → عربي وRTL، وإلا إنجليزي وLTR).
- الحفظ على القرص في `server/data/notes.json` حتى تبقى الملاحظات بعد إعادة تشغيل الـ API.

حدود الحقول: العنوان حتى 200 حرف، والنص حتى 8000 حرف.

## واجهة REST باختصار

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | فحص الصحة (`persist`: `ok` أو `degraded` أو `unavailable`) |
| `GET` | `/api/notes` | قائمة الملاحظات (الأحدث أولاً حسب `updatedAt`) |
| `GET` | `/api/notes/export` | تنزيل كل الملاحظات (`?format=json` أو `md`) |
| `GET` | `/api/notes/:id` | ملاحظة واحدة |
| `POST` | `/api/notes` | إنشاء `{ title, body? }` |
| `PUT` | `/api/notes/:id` | تحديث جزئي `{ title?, body? }` |
| `DELETE` | `/api/notes/:id` | حذف ملاحظة |

التفاصيل الكاملة للطلبات والاستجابات والأخطاء في [توثيق واجهة البرمجة](docs/api.md).
